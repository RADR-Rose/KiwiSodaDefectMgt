KiwiSoda KS.001.00__ InternalTesting Priority1 [Feature: PM Dashboard - Dashboard Filtering (Status)]
Concise bug title: Dashboard status filter (Ongoing / Completed) has no effect on project list
Tester: RADR-R

[Summary]
On the PM Dashboard, selecting a status filter (e.g., Ongoing, Completed)
does not filter the project list. All projects continue to be displayed regardless
of the status filter option chosen.

[Precondition]
Software version: KS.001.00__
Software configuration: Standard
Hardware specifications: Standard test machine
Network configuration: [X] Wi-Fi

- User must be connected to the internet.
- User must be logged in as Project Manager using the test account
  (email: 22-1-00856@vsu.edu.ph ; password: 12345678).
- Multiple projects with different statuses (Ongoing, Completed) must exist.

[Steps to reproduce]
1. Log in as Project Manager.
2. Navigate to the PM Dashboard.
3. Locate the status filter control (Ongoing / Completed).
4. Select "Ongoing" from the filter options.
5. Observe the project list.
6. Repeat by selecting "Completed".

[Actual results]
All projects remain visible regardless of which status filter is selected.
The project list does not update or narrow down to match the selected status.
The filter control appears interactive but produces no change in the displayed results.

[Expected results]
Selecting a status filter should narrow the project list to only show projects
matching the selected status:
- "Ongoing" → only projects currently in progress
- "Completed" → only fully completed projects
